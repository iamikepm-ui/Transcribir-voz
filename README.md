# Dictado

App web para dictar por voz y convertirlo en texto en español, lista para copiar o enviar por WhatsApp.

**Abrir:** https://iamikepm-ui.github.io/Transcribir-voz/

- **En directo**: reconocimiento de voz de Google integrado en Chrome (texto mientras hablas, necesita conexión).
- **IA precisa**: Whisper Large v3 Turbo (OpenAI) o Cohere Transcribe, modelos gratuitos de código abierto que se ejecutan en el propio móvil con [Transformers.js](https://huggingface.co/docs/transformers.js). La primera vez descargan el modelo; después funcionan sin cobertura.

Botón grande para hablar, pitido al empezar y al parar, copia automática y botón de WhatsApp.
