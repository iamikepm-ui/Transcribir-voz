    Ajustes y ayuda

    ⚡ Rápido: reconocimiento de voz de Google (Chrome). Ves el texto mientras hablas. Necesita conexión.

    🎯 Preciso: Whisper (OpenAI) o Cohere Transcribe, modelos abiertos y gratuitos de Hugging Face que funcionan dentro de tu móvil. Ponen tildes, comas y signos solos y aguantan bien el ruido del coche. La primera vez descargan el modelo (con wifi); después funcionan sin cobertura.

    🌐 Traducir: español ↔ catalán con el traductor integrado de Chrome (dentro del móvil). Si tu Chrome no lo tiene, se usa Opus-MT (Universidad de Helsinki, ~80 MB la primera vez), algo menos fino. Revisa la traducción antes de enviarla; puedes deshacerla.

    Consejo: menú ⋮ de Chrome → «Añadir a pantalla de inicio» para abrirla como una app.
